# Vortextech-cybersec-week1

Vortextech CyberSec Internship — Week 1: OWASP Top 10 Research
What this is
This repository contains my Week 1 deliverable for the Cyber Security Internship Track. The goal of Week 1 was to build a theoretical foundation in web application security by researching the OWASP Top 10, the industry-standard list of the most critical web application security risks.
What's inside
`OWASP-Top-10-Week1-Research.md` — The main deliverable. It covers 5 vulnerabilities from the current OWASP Top 10 (2025 edition):
Broken Access Control
Injection
Security Misconfiguration
Authentication Failures
Cryptographic Failures
For each vulnerability, the document explains:
What it is, in plain language
How an attacker could exploit it (with a simplified example)
A real-world breach or case where it caused harm
At least one practical way developers can prevent or mitigate it
It closes with a short personal reflection on which vulnerability was most surprising and why.
